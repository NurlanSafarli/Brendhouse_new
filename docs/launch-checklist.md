# Launch checklist

- [ ] Phase 1 complete: full schema, reviewed migration, DB constraints and repeatable import tests
- [ ] Catalog verified; development seeds excluded from APIs/search/feeds
- [ ] Approved policy versions used consistently, regional rules confirmed
- [ ] Guest checkout and payment-provider sandbox end-to-end tests
- [ ] OTP provider and rate limits verified; no unverified accounts/cards
- [ ] Bonus rates/caps/tiers/stacking approved; debt offsets future earnings
- [ ] POS synchronization/reconciliation and concurrent redemption tests
- [ ] Admin authorization and audit enforcement tests
- [ ] Real catalog, media and legacy URL inventories; validated redirects
- [ ] Privacy/legal/consent review, operational backup restore and rollback drills
- [ ] Accessibility, mobile performance, SEO, monitoring and production signoff
